StockCalzadoApp es una aplicación móvil Android desarrollada como Trabajo Final del Ciclo Formativo de Desarrollo de Aplicaciones Multiplataforma. El proyecto consiste en una solución orientada a la gestión de stock en una tienda de calzado deportivo, prestando especial atención al flujo de trabajo entre la zona de tienda y el almacén.
La aplicación permite registrar productos de calzado, asociarlos a diferentes tallas, asignar un código de barras a cada talla y controlar el stock disponible. Además, incorpora un sistema interno de pedidos: desde tienda se puede escanear o introducir manualmente un código para solicitar un producto al almacén; desde almacén se puede completar el pedido, marcarlo como fallido y consultar el historial de solicitudes.
La solución se ha desarrollado en Kotlin para Android. A nivel técnico se ha utilizado una arquitectura basada en Clean Architecture y MVVM, separando la presentación, el dominio y los datos. La persistencia se ha implementado con Room/SQLite, mientras que la lectura real de códigos de barras se ha integrado mediante ML Kit Barcode Scanning y CameraX. La entrada manual se mantiene como alternativa para garantizar la continuidad del uso si el escaneo falla o no está disponible.
El resultado final es un prototipo funcional y defendible que permite demostrar un proceso realista dentro de una tienda de calzado: entrada de productos, consulta de tallas, creación de pedidos desde tienda, gestión de solicitudes en almacén, actualización automática del stock, uso de imágenes de producto y escaneo real de códigos de barras.
